# Skill-and-You

Atelier : présenter une page de code

Ce projet est un exercice pratique portant sur l'affichage et la mise en forme de snippets de code (HTML et CSS) directement sur une page web.

🔍 Aperçu du projet :
La page permet d'afficher le propre code source (HTML et CSS) de la page sous la forme de blocs de code lisibles et stylisés façon terminal ou éditeur de texte.

🏷️ Notions et balises HTML abordées :
Balise <pre> : utilisée pour conserver la mise en forme, les espaces et les sauts de ligne du texte source.
Entités HTML (&lt; et &gt;) : emploi des entités pour afficher les caractères de balises < et > sans qu'ils soient interprétés par le navigateur.
Balise <span> : permet d'appliquer des styles spécifiques (ex: mise en évidence de la classe .texte) à l'intérieur du bloc de code.

🎨 Mise en forme CSS :
Blocs de code (thème sombre) : utilisation d'un fond noir (background: black), d'un texte clair (color: antiquewhite) et d'une marge interne (padding: 10px) pour simuler la coloration d'un éditeur.
Titres de sections : ajout d'une bordure inférieure sous les éléments <h2>.
Sensibilité aux détails : coloration personnalisée pour les zones de remplacement (.texte).
